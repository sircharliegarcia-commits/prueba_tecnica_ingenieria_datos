# Ejercicio 2 – KPIs de Calidad y Trazabilidad de Datos

Este módulo complementa el Ejercicio 1 de creación del dataset de teléfonos
incorporando un mecanismo de veeduría de calidad de datos, trazabilidad y
gobierno del dato.

## Objetivo
Proveer a los equipos de negocio indicadores claros sobre la calidad,
confiabilidad y evolución de los teléfonos de los clientes.

## Alcance
- KPIs de calidad de datos
- KPIs de trazabilidad
- Automatización mediante CI/CD
- Soporte para toma de decisiones del negocio

## Relación con el Ejercicio 1
Los KPIs se calculan a partir del dataset curado generado en el Ejercicio 1.
